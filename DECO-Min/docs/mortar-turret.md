# 固定砲台（遠距離ザコ敵）

## 攻撃仕様

- 索敵、視線遮蔽、認識の記憶、ターゲット管理、ダウン／封印は既存 Enemy と共通。
- 本体は移動しない。旋回するのは TurretPivot 以下の本体2のみ。本体1、弾は別オブジェクト。
- 準備1.5秒。準備開始位置を中心とする半径2mの円を判定範囲とする（水平距離）。
- 準備開始0.5秒で着弾地点を確定。それまでは範囲内のプレイヤー位置を記録する。範囲を出たら最後の範囲内位置を固定し、再入場しても変更しない。
- 確定前の対象消失や視線遮蔽は準備を中止。確定後は見失っても固定地点へ発射。ただし死亡、ダウン、スタン、帰還などの状態遷移は中止する。
- 上部は基本角速度＋角度差に比例する角速度で旋回し、上限速度を設ける。水平・上下角度制限なし。砲身は計算した射出速度方向を向く。
- 準備終了時に照準が合っていなければ発射せず再準備。回転中は発射しない。
- 飛行時間3秒。初速は `(着弾点 - 発射点) / 時間 + 上方向 * 重力 * 時間 / 2`。途中で障害物に衝突した場合はその位置で爆発。
- 着弾時は半径2mの球で判定し、同じ被ダメージ対象には一度だけ10ダメージ。発射元と他の Enemy は対象外。
- 発射から4.5秒のCT。索敵状態が変わってもCTを短縮しない。
- 数値は Inspector から調整可能。既存 EnemyBullet の Direct / Arc は維持し、砲台から発射するときだけ時間指定の範囲攻撃を使う。

## 配置とモデル差し替え

`Assets/Resources/Prefab/Enemy/Mortar/MortarTurret.prefab` を配置する。黄色のプリミティブは仮モデル。
本体1は Body1、本体2は TurretPivot/Body2 を差し替える。TurretPivot のローカル +Z が砲口方向。
FirePoint は TurretPivot の子とし砲口に置く。本体の Collider は見た目に合わせて調整する。
EnemySeparation の小さい判定は共通処理で生成される。砲台は押されず、動く敵が砲台から離れる。
弾のモデルは別 Prefab `MortarShell.prefab`。リグは不要。

## 検証

`DECO-Min/Create Mortar Prefabs` で仮モデルの Prefab を新規生成できる（既存ファイルは上書きしない）。

2026-10-19、Unity 6000.3.14f1 のバッチモードで以下を確認済み。

- 高低差、水平距離、真下の目標への3秒着弾の計算。
- 0.5秒での照準固定、範囲退出後の最終位置保持、再入場での追尾再開防止、範囲境界。
- 複数 Collider を持つ対象へのダメージ重複防止、範囲外へのダメージなし。
- 準備前・準備途中の発射防止、発射後CTと状態再入場時のCT維持。
- 敵同士の押し合いによる移動防止、プールからの再出現後もNavMesh無効。
- Play Mode の空シーンに床・標的・完成Prefabを生成し、実際の Update と物理演算で索敵から範囲ダメージまで確認。準備中のダメージなし、着弾で10ダメージ、本体の静止（物理誤差許容1mm）と上部のみの回転を確認。

検証専用コードはユーザーの了承により検証後に削除。削除後のUnityバッチコンパイルも終了コード0で完了。正式モデル・既存ゲームシーンでの見た目と難易度の調整は別途必要。
